SS Color Neo

A reusable color picker with a hex field, popup panel, color swatch, shade slider, and EyeDropper support when the browser exposes it.

pnpm install ss-color-neo
Click the button to render picker inside popover.
This picker uses historyEnabled: true, so the Recent group appears after picking colors.
Mounted selector is initialized with the color option.
History is off by default. This demo turns it on to show separate Favorites and Recent sections.
